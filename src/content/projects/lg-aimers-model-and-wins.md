앞 두 편에서 문제의 지형과 검증 규율을 세웠다. 이 편은 그 위에서 실제로 무엇을 만들었고, 무엇이 점수를 올렸는지의 기록이다.

## 최종 구조 — 두 계열의 단순 평균

```
최종 = 0.5 × v4ri(팀원, 신경망 계열) + 0.5 × v5(우리, 트리 계열)
```

확률 공간에서의 단순 선형 평균이다. 항등식으로 푼 최적 가중치도 0.5186으로 0.5와 사실상 같았고(이득 +0.04), 그래서 **혼합 가중치 축은 완전히 닫힌** 것으로 확인됐다. 두 모델이 비슷한 실력이면서 서로 다른 곳에서 틀렸기 때문에, 이 단순 평균이 각 단독보다 훨씬 좋았다.

### 우리 v5 내부 (트리 계열, CatBoost)

v5는 세 개의 팔을 잔차 위에 쌓은 구조다.

```python
residual_a = mean(model_A + seed 2025..2028)                 # A: 주력, 5시드 평균
r_gate     = sqrt(p_rel * b_rel)                             # 신뢰도 기하평균
r_safe     = residual_a + r_gate*(residual_b_R - residual_a)  # R 행
f_gate     = support / (support + 50.0)
f_safe     = residual_a + f_gate*(residual_b_F - residual_a)  # F 행
residual_b = where(game_type=="F", f_safe, r_safe)           # game_type 라우팅
p = prior + 0.30*residual_a + 0.40*residual_b + 0.30*residual_c
```

- **A팔** — base 121 특징 + `cur14` + `allrates 마스킹`으로 2019–2024 전체를 풀링해 학습(target = 성공 − anchor, 5시드). 실효 가중치는 게이트를 감안하면 약 0.62~0.68로, 사실상 모델의 중심축이다.
- **B팔** — A 위의 볼록결합이다. `game_type`으로 R행은 allblocks 계약(209 특징 = 계약 123 + 잠재 실력 86)을, F행은 별도 F 전용 모델을 라우팅한다. §5 규정이 허용하는 유일한 라우팅이 이 game_type row-local 분기였다.
- **C팔(RealMLP)** — 성능이 아니라 **다양성**이 존재 이유다. A와의 예측 거리가 B의 7~30배라, 앙상블에 넣을 새로운 오류 방향을 공급했다.

### 팀원 v4ri 내부 (신경망 계열)

v4ri는 CatBoost·FT-Transformer·MLP·회귀 등 6개 컴포넌트의 블렌드였고, 결정적으로 **TrackMan 물리량(구속·회전·무브·릴리스)을 사용**했다. 이건 v5에는 없는 정보원이었고, 정확히 그래서 v4ri가 혼합에서 값을 했다. 후처리로 연도별 절편 보정(2024 −0.0311 = 기저율 하락의 명시적 외삽)도 들어갔다.

## 무엇이 점수를 올렸나

성공한 개선을 모아 보면 하나의 패턴이 보인다.

실제 리더보드 앵커로 보면, 두 모델은 각각 1104·1100으로 비슷했지만 섞자 1135가 됐다. 이 <b>+31점은 성능 향상이 아니라 순수한 다양성 이득</b>이다 — 팀 우위 전부가 여기서 왔다.

성공한 개선의 전체 목록과, 각각이 왜 통했는지:

- **시드 앙상블 (LB +10)** — C 모델의 시드 평균. 분산 감소 항등식 그대로다. "항등식은 이월된다"의 가장 직접적인 증거였고, 초기의 유일한 확실한 이월 성공이었다.
- **모델 혼합 0.5:0.5 (+31)** — 위 그림. 함수형 다양성으로 서로 다른 오류가 상쇄됐다.
- **cur14 (+1.7)** — as-of 차분으로 "현재 시즌까지의" 이벤트 비율을 복원하고 2024말 anchor 대비로 넣은 것(§4-safe row-local). 동시대·연도적응 신호라 체제 변화에 강건했다. 캘리브레이션 이득이라 미래로 전이됐다.
- **allrates 마스킹** — pre-2023 학습 행의 rate-history를 비워, 옛 체제의 통계가 새 체제를 오염시키지 못하게 막았다. 체제 경계 처리.
- **B팔 R/F 라우팅 (+2)** — 현재 행의 game_type만으로 F/R 전용 모델을 고름. R과 F는 완전히 다른 체제라서.

## 하나의 공통점

이 목록에는 공통점이 있다 — **성공한 개선은 전부 캘리브레이션 / 체제 강건성 / 다양성 / 항등식 종류다. 판별력(ρ)을 직접 끌어올린 것은 하나도 없다.**

이 사실이 대회 후반의 방향을 결정했다. 점수 식이 `Score ≈ 100000ρ²`인데 우리가 성공한 개선은 죄다 ρ 바깥의 것들이었다는 것은, 진짜 벽이 ρ 그 자체에 있다는 뜻이었다. 그 벽을 어디까지 밀어 봤고 왜 막혔는지가 마지막 편의 내용이다.
