이 대회에서 가장 크게 데인 건 모델이 아니라 검증이었다. 로컬에서 선명하게 좋아 보이던 개선이 리더보드에서 사라지거나 오히려 마이너스가 되는 일이 반복됐다. 이 편은 그 실패들에서 뽑아낸 **"무엇을 믿을 수 있는가"의 규율**에 대한 기록이다. 개인적으로는 대회에서 배운 것 중 실무로 가장 오래 남을 부분이라고 생각한다.

## 이월 법칙

수많은 실험 끝에 도달한 결론은 단순했다. **이월되는(=미래·평가에서도 유지되는) 것은 두 가지뿐이다.**

1. **수학적 항등식** — 예: 시드 앙상블의 분산 감소량 `이득 = 분산 × (1 − 1/S)`.
2. **목표(리더보드) 위에서 직접 잰 양** — 예: 두 모델을 섞을 때의 라벨 상쇄량.

그 외에 **과거 연도에 맞춘 것은 예외 없이 실패했다.** 이 문장을 머리로만 알던 시기에 가장 비싼 수업료를 냈다.

## −4.34 사건 — 최강 카드가 무너지다

A팔(주력 트리 모델)을 개선하는 카드를 만들었다. 학습률을 낮추고 반복을 늘리고, 카운트 조건부 특징을 더하고, 최근 3년 반감기 가중을 넣었다. DEV 검증 결과는 대회 통틀어 가장 강력했다.

```
DEV 3폴드:  A 단독 +18.52 (3/3 유의)
            A + B 전파 +33.05 (t = 8.45 / 6.27 / 5.89)   ← 세션 최강 검증
리더보드:   1135.33 → 1130.99 = −4.34 (참값)
```

t = 8.45짜리 신호가 실전에서 정확히 반대로 나왔다. 원인을 사후에 셋으로 분해했다.

1. **대리 계약으로 판정** — 배포되는 B팔은 209개 특징인데 판정은 123개 특징의 축소판으로 했다. 이득이 7~20배 부풀려졌다.
2. **체제 경계를 가로지른 폴드 평균** — 2022·2023·2024를 평균냈는데, 2022→2023이 구조가 바뀌는 경계였다(아래).
3. **국소→LB 부풀림 미적용** — 국소 추정은 LB를 약 1.73배 부풀린다.

## 체제 경계 — 폴드는 표본이 아니라 사건이다

인접 두 해의 공통 투수(200구 이상) 성공률 순위상관을 재 보면, 대부분 0.67~0.71인데 **2022→2023만 0.553으로 무너진다.**

```
2019→20  0.683    2021→22  0.676    2023→24  0.711 (최고)
2020→21  0.670    2022→23  0.553 (무너짐) ← 체제 경계
```

즉 데이터는 두 체제(2020–2022 / 2023–2024)로 나뉘고, 2025는 체제 이후다. 여기서 "누가 잘하는지의 구조 자체가 바뀌었다"(역전 축 연도간 변동의 92%가 체제, 8%가 표집). 그래서 **깨끗한 폴드는 2023 적합 → 2024 평가 단 하나뿐**이고, 세 연도를 평균낸 것이 −4.34의 두 번째 원인이었다.

## 규율로 만든 체크리스트 (R1~R10 발췌)

같은 실수를 반복하지 않으려고, 배포 전 통과해야 하는 규칙을 결과를 보기 전에 적어 두었다.

- **R1 — 검증은 배포 시뮬레이션이다.** 얼릴 값은 전부 평가 연도보다 엄격히 이전에서. (평가에서 재면 +9.53, 직전에서 얼리면 +4.94로 갈렸다.)
- **R2 — 배포되는 산출물로 재라.** 대리물 금지. (123 특징 대리 계약 = 7~20배 부풀림.)
- **R3 — 혼합 수준에서 보고하라.** 팔 하나의 개선이 혼합으로 전달되는 비율이 0.068~0.632로 요동쳤다. 팔 +33 → 혼합 +2.24를 겪었다.
- **R5 — 폴드 하나를 시나리오 전수로 보강하고, 최악으로 판단하라.**
- **R9 — 국소 추정에는 LB 할인 0.58을 곱해 보고하라.** (국소 상쇄량 232.97 vs LB 실측 125.5 = 1.73배.)

## 리더보드에는 표집 오차가 없다

마지막으로 못 박아 둔 사실 하나. 이 대회의 Public 리더보드는 **전체 test의 100%**였고 분할이 없었다. 즉 두 제출의 점수 차이는 표집 잡음이 아니라 참값이다. 초기에 "짝지은 표준오차"를 계산한 건 틀린 접근이었다. 의미 있는 불확실성은 오직 **"국소 추정으로 LB를 예측할 때의 폭"** 하나뿐이었고, 그래서 국소 이득은 언제나 할인해서 말하는 습관이 생겼다.

이 규율 위에서 실제로 무엇을 세웠는지 — 모델 아키텍처와 성공한 개선은 다음 편에서 다룬다.
