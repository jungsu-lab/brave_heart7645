LG Aimers 9기 / DACON 236743은 KBO 투구 데이터로 각 투구가 제구에 성공할 확률(`control_success`)을 예측하는 대회였다. 팀원과 2인으로 참가했고, 최종 **1135.33점**(우리 v5 + 팀원 v4ri 혼합)에서 마무리했다. 이 시리즈는 그 여정을 문제 → 검증 → 모델 → 벽의 네 편으로 나눈 첫 편이다.

시작은 언제나 "무엇을 맞혀야 점수가 오르고, 무엇이 금지돼 있는가"를 못 박는 일이었다.

## 채점 구조 — 소수점 아래가 순위다

맞고 틀리고가 아니라 **확률을 얼마나 잘 맞히느냐**를 Brier 점수로 채점했다.

```
Score = 100000 × (1 − Brier / 0.249807)
      = 400,309.038578 × (완벽 − Brier)
      ≈ 100000 × ρ²        (ρ = 예측과 실제의 상관)
```

기준값 `0.249807`의 정체는 **2024 시즌 전체의 기저율 분산** p(1−p)이다. 대회가 마지막 학습 연도를 기준점으로 삼은 것이고, 이 사실은 test(2025)에 대해선 아무것도 알려주지 않는다는 뜻이기도 했다. `Score ≈ 100000ρ²`라는 근사는 대회 내내 나침반이 됐다 — 점수를 올리려면 결국 **판별력 ρ**를 올려야 한다는 것을 이 식이 말해 줬다.

## 데이터와 채점의 함정

```
train.csv             1,475,092행 · 2019~2024 · 라벨 있음 · 49열
test.csv              5행짜리 스모크 (진짜 test는 서버에만: 2025, 245,789행)
trackman_history.csv  1,793,079행 · 투구별 물리량 30열
```

가장 먼저 부딪힌 함정이 여기 있었다. 공개된 `test.csv`는 5행짜리 확인용이고, **실제 채점은 대회 서버가 우리가 제출한 코드+모델 번들을 자기 test로 직접 실행**하는 방식이었다(7분대). 즉 로컬에서는 test 예측을 만들 수조차 없었다.

이 구조를 초반에 이해하지 못해 실수도 했다. 서버가 5행을 49,158번 복제해 만든 산출물을 실제 예측으로 착각해 "예측 평균 0.452를 2025 수준으로" 읽었다가 분석 세 번을 통째로 폐기했다. 고유 예측값이 5개뿐인 파일의 평균·분산은 아무 의미가 없었다.

test 행이 받는 입력은 **48개의 as-of 피처**뿐이었다 — 식별/시간, 카운트, 점수/주자, leverage, 투수·타자 개체, 그리고 투수·타자의 시즌 누적 비율(성공/역전/한가운데/볼/스트라이크). **구속·무브·로케이션·투구 시퀀스·game_id는 test에 없었다.** 무엇을 쓸 수 있는지의 경계가 곧 모델의 경계였다.

## 타겟을 100% 복원하다

라벨이 어떻게 만들어지는지부터 뜯었다. as-of 열의 차분(같은 선수 연속 행에서 비율×개수의 증분)으로 **투구별 결과를 소수점 여섯 자리까지 정확히 복원**했다(복원 success가 실제 라벨과 완전 일치, 전 연도 147만행, 유효 99.83%). 이 복원이 나중에 성공한 개선(cur14)의 토대가 된다.

복원 과정에서 타겟의 곱셈 구조도 드러났다.

```
P(성공) = P(¬역전) × P(¬한가운데) × [0.61·P(볼) + 0.93·P(스트) + 0.96·P(인플)]
```

다만 이 곱셈 독립 가정은 정확히는 맞지 않았다(구조식 0.51642 vs 실제 0.50311, 1.3~2.0%p 어긋남). 이 어긋남이 훗날 "타겟을 구조 그대로 분해해 모델링"하는 접근이 실패한 이유의 일부가 된다.

## 규정이 만든 벽

이 대회에서 규정(`§2/§4/§9`)은 성능보다 우선했고 예외가 없었다. 핵심만 옮기면:

- **§2** — 평가 데이터 전체의 평균·분위수·순위·빈도·분포 사용 금지. 평가로 fit한 scaler/calibrator 금지. 사후 평균맞춤·raking·clipping 금지.
- **§4** — 단일 행 / 전체 행 / 셔플 / 추가 행 / 중복 행의 **5중 불변성**. 한 행의 예측이 다른 test 행에 의존하면 위반.
- **§9** — 모든 상태·보정값은 공식 학습 데이터만으로 미리 동결. **LB에서 역산한 상수는 위반**, 학습 추세로 정한 값은 합법.

이 규정이 실제로 벽이었다. §4는 **투구 시퀀스 신호를 원천 차단**했다 — 나중에 잔차 자기상관(lag1 = 0.0226)이라는 세션 단일 최강 신호를 발견했지만 셔플 불변성 때문에 쓸 수 없었다. §2는 분포 시프트 문헌의 대표 기법(Test-Time Adaptation, adversarial test 가중)을 통째로 막았다.

무엇을 할 수 있고 없는지의 지도를 이렇게 먼저 그려 두었기에, 이후의 모든 실험은 "성능이 나오는가"와 "규정을 통과하는가"를 항상 함께 물으며 진행할 수 있었다. 다음 편은 그중 **검증 방법론** — 국소적으로 좋아 보이는 것이 왜 리더보드에서 무너지는가에 대한 기록이다.
